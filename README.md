# Java Game Engine + Tile Map Editor

Lightweight 2D game engine and tile map editor built in Java.

---

##  Overview

This project combines a custom-built engine with an integrated level editor. It supports rendering, input, physics, and a full tile-based workflow for designing and testing game worlds.
